Fundamentos do Design de Interfaces (UI/UX)

Sobre o projeto

Trabalho sobre os fundamentos do design de interfaces digitais, abordando os conceitos de UI e UX e sua importância na criação de sites e aplicativos.

Objetivos

Compreender a diferença entre UI e UX.

Identificar princípios de design em interfaces digitais.

Analisar pontos positivos e oportunidades de melhoria.

Propor melhorias para a experiência do usuário.
